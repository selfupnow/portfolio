# SELFUPNOW — Fitness Growth Studio

> **"Content isn't the product. The outcome is."**

A production-quality website for **SelfUpNow**, an elite Fitness Growth Studio engineered to help online fitness coaches turn Instagram attention into qualified, high-ticket coaching opportunities.

---

## 💎 Brand Positioning & Core Principles

- **Category:** Fitness Growth Studio (Positioning, Content Architecture, Lead Systems)
- **Target Audience:** Online Muscle-Building, Fat-Loss, and Physique Transformation Coaches (2K–50K followers, established offer, proven testimonials)
- **Aesthetic:** Editorial, confident, minimal, high-end creative studio, performance-driven.
- **Strict Brand Integrity:** Faceless brand identity. Zero fake client logos, zero fabricated revenue screenshots, zero inflated statistics, zero generic stock photography, zero neon gym-bro graphics.

---

## 🎨 Design Tokens

- **Near Black:** `#0A0A0A` (Primary Background)
- **Warm White:** `#F3F0EA` (Editorial Headlines & Contrast Text)
- **Charcoal:** `#161616` (Card Surfaces & Elevation)
- **Muted Grey:** `#8B8B8B` (Micro-labels, Subtitles, Meta)
- **Electric Lime:** `#C7FF3D` (Accent: CTA buttons, interactive states, hover auras)
- **Typography:** `Inter Tight` (Display & Headlines) + `Inter` / `Manrope` (Body & Interfaces) + `JetBrains Mono` (System tags)

---

## ⚡ Core Sections & Feature Highlights

1. **Fixed Header Navigation:** Dynamic compact scrolling state, top-edge scroll progress indicator (`h-[2px] bg-[#C7FF3D]`), and full-screen mobile menu.
2. **Editorial Hero Section:** High-impact typography (`TURN ATTENTION INTO CLIENTS.`), interactive 3D phone chassis tracking cursor movement with realistic Instagram profile simulation (`@atlasform`), floating DM & lead alerts, and 6-stage conversion flow tags.
3. **The Problem (`YOUR CONTENT ISN'T THE PROBLEM`):** 3 large diagnostic statement cards with an interactive gap vs fix inspection drawer.
4. **The SelfUpNow System (`FOUR STEPS. ONE GOAL.`):** 4 expandable numbered blocks (`01 POSITION`, `02 CREATE`, `03 CONVERT`, `04 MEASURE`) with deliverables and metric targets.
5. **Interactive Content Flow (`ONE REEL. MULTIPLE JOBS.`):** Interactive 6-step pipeline visualizing how a single reel moves from Attention to Call Booking.
6. **Content Strategy (`WE DON'T POST. WE POSITION.`):** Horizontally scrollable content strip featuring the 6 pillars (Attention, Education, Authority, Proof, Connection, Conversion).
7. **Positioning Transformation (Before / After):** Diagnostic hook contrasts comparing generic fitness posts with SelfUpNow high-intent angles.
8. **The Lead Path (`FROM REEL TO REAL OPPORTUNITY`):** Full-width 8-stage pipeline with interactive inspector detailing *What Happens*, *Why It Matters*, and *What SelfUpNow Does*.
9. **Concept Demonstration (`ATLAS FORM`):** Transparently labeled `CONCEPT / DEMONSTRATION` project featuring profile transformation, reel hooks, interactive DM qualification chat simulator, and intake structure.
10. **Honest Telemetry Dashboard (`WE MEASURE WHAT MATTERS`):** Empty dark analytics suite with `—` placeholders and the trust-building commitment: *"We don't manufacture case studies. We build them. Your real numbers go here."*
11. **Who We Work With:** Hypertrophy, Fat Loss, and Physique niches with clear qualifying criteria checklist.
12. **Why SelfUpNow:** 5 strategic non-generic pillars (Strategy First, Fitness Specialization, Business-Led Content, Transparent Measurement, Direct Collaboration).
13. **30-Day Growth Pilot:** Transparent risk-managed pilot package with full deliverables breakdown, currency toggle (INR / USD), and honest disclaimer.
14. **Acquisition Economics (`ONE CLIENT CAN CHANGE THE MATH`):** Benchmark equation (₹30,000 × 4 mos = ₹1,20,000 LTV) + interactive dual-slider ROI calculator.
15. **6-Stage Process Roadmap:** Step-by-step workflow (Audit, Strategy, Production, Launch, Optimize, Scale).
16. **Cinematic Final CTA:** Massive editorial typography with direct email and Instagram paths.
17. **Interactive 3-Step Application Modal:** Complete multi-step intake flow with instant feedback and celebratory confetti.

## 🛠️ Local Development & Scripts

### 1. Start Development Server
```bash
.\run.cmd npm run dev
# Or if node is in system PATH:
npm run dev
```
The server will be available at: `http://localhost:3000`

### 2. Production Build
```bash
.\run.cmd npm run build
```

### 3. Preview Production Build
```bash
.\run.cmd npm run preview
```
